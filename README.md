# 자동 클릭기

모든 OS 공통: 지정한 위치(최대 6곳)를 매 주기(4~7초)마다 지정한 순서대로 클릭하고, 클릭 사이 간격은 0.3~0.8초입니다.
단축키는 **F8: 위치 추가 / F9: 일시정지·재개 / F10: 종료 / F7: 위치 모두 지우기** 이고, 전역으로 감지하므로 다른 창을 쓰고 있어도 반응합니다.

## Windows

추가 설치 없이 Python만 있으면 됩니다. bat 파일이 `py` 또는 `python` 을 자동으로 찾고, 없으면 설치 안내를 띄웁니다.

- `자동클릭 실행.bat`: 마우스를 실제로 움직여 클릭 (`autoclick.py`)
- `자동클릭 백그라운드 실행.bat`: 마우스를 움직이지 않고 창에 클릭 신호를 보냄 (`autoclick_background.py`)
  - 스크립트는 커서를 움직이지 않지만, 일부 프로그램(특히 게임)은 클릭 신호를 받으면 스스로 커서를 끌어가거나 창을 앞으로 가져옵니다. 그런 경우 클릭 직후 커서 위치와 앞에 있던 창을 원래대로 되돌립니다.
  - 마우스 버튼을 누르고 있는 동안(드래그 등)에는 클릭을 잠시 미룹니다.
  - 프로그램이 클릭을 처리하는 방식 때문에 완전히 막을 수 없는 경우도 있습니다. 그럴 때는 가상 머신이나 Windows 샌드박스 안에서 대상 프로그램과 이 스크립트를 함께 실행하면 내 마우스와 완전히 분리됩니다.
- 위치 개수는 각 파일 위쪽의 `POINTS = 6` 을 바꾸면 최대 개수가 바뀝니다.

## macOS

추가 설치 없이 기본 `python3` 로 실행합니다. Finder에서 `자동클릭 실행 (맥).command` 를 더블클릭하거나 터미널에서 `./auto.sh` 를 실행하세요.

- 처음 실행할 때 **시스템 설정 > 개인정보 보호 및 보안** 에서 터미널에 **손쉬운 사용** 과 **입력 모니터링** 권한을 줘야 클릭과 F7~F10 키가 동작합니다.
- 맥북 키보드는 기본 설정이면 **fn 키를 같이 눌러야** F7~F10으로 인식됩니다(fn+F8). 시스템 설정 > 키보드 에서 'F8, F9 등의 키를 표준 기능 키로 사용'을 켜면 fn 없이 됩니다. 권한을 준 뒤 터미널을 다시 실행하세요.
- 맥에는 백그라운드 모드가 없고, 마우스를 실제로 움직여 클릭한 뒤 원래 위치로 돌려놓습니다. 커서를 화면 왼쪽 위로 옮기면 비상정지합니다.
- 위치 개수는 `autoclick_mac.py` 위쪽의 `POINTS = 6` 을 바꾸면 최대 개수가 바뀝니다.

## Linux (X11)

```bash
./auto.sh   # 처음 실행 때 setup_linux.sh 가 자동으로 실행됩니다
# 커서를 이동하는 일반 모드:
./자동클릭\ 실행.sh
```

- Python 3, X11 데스크톱과 python-xlib가 필요합니다. 설치 스크립트는 프로젝트 내부 `.venv`만 만듭니다.
- 네이티브 Wayland와 화면 없는 서버에서는 실행하지 않습니다.
- F8: 현재 커서 아래 창/좌표를 클릭 위치로 추가합니다. 최대 6곳까지이며(1곳만 지정해도 바로 클릭 시작), 다 찬 뒤 F8을 누르면 처음부터 다시 지정합니다. F7로 언제든 모두 지울 수 있습니다. 선택 전에는 클릭하지 않습니다.
- 매 주기마다 지정한 위치를 지정한 순서대로 클릭하고, 클릭 사이 간격은 0.3~0.8초입니다.
- 위치 개수는 `--points` 로 바꿀 수 있습니다. 예: `./auto.sh --points 1` (한 곳만), `--points 3` (세 곳).
- F9: 일시정지/재개. F10 또는 Ctrl+C: 종료. F7: 위치 모두 지우기.
- 주기 간격 4~7초, 누름 시간 0.05~0.12초, 위치 흔들림 ±5px.
- 백그라운드 모드는 커서를 옮기지 않고 X11 ButtonPress/Release 이벤트를 전송합니다. 앱에 따라 합성 이벤트를 무시할 수 있으며, 전송 로그가 실제 버튼 동작을 보장하지 않습니다.
- 대상 창이 숨겨지거나 최소화되면 클릭을 건너뜁니다. 닫혔거나 배치가 바뀌면 F8로 다시 지정하세요.
- 일반 모드는 실제 포인터를 움직이며 클릭 뒤 원래 위치로 복구합니다. 커서를 화면 왼쪽 위로 옮기면 비상정지합니다.

터미널을 닫아도 선택 대기 상태를 유지하려면 같은 X11 데스크톱에서:

```bash
nohup ./auto.sh > autoclick.log 2>&1 &
echo $! # 종료할 때 kill PID
```

클라우드에서 실행한 프로그램은 사용자의 Windows 데스크톱을 제어하지 않습니다.

## 테스트

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m py_compile autoclick_linux.py
bash -n setup_linux.sh '자동클릭 실행.sh' auto.sh '자동클릭 실행 (맥).command'
```

실제 클릭 통합 검증은 X11 데스크톱의 테스트 창에서 별도로 해야 합니다.
